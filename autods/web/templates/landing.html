How it works

Five steps, and you approve each one.

There is no black box. At every stage you see what it found and decide what happens next.

01

Load your data

Point it at a CSV or spreadsheet. It reads the structure and quietly fixes the obvious mess, like stray text, wrong types, and duplicate rows.

02

Explore and check

You get clear charts with the code behind them, and a set of data checks that flag leakage, ID columns, and other traps before you ever model.

03

Clean

It suggests how to handle missing values and messy columns, and waits for your approval before touching the data.

04

Model

It ranks more than thirty algorithms, tunes the winner, and can even blend the best few into an ensemble. You make the final call.

05

Understand

You get the metrics that matter, an interactive dashboard, a written analysis, and a model you can download or point at new data.

What you get

More than a score.

Every run ends in something you can actually use, read, and share.

Data quality checks

It audits the data for leakage, ID columns, duplicates, and outliers, and warns you before a misleading model ever gets trained.

A real model hub

More than thirty algorithms cross checked on your data, with tuning and ensembles, so you are never trusting a single guess.

An interactive dashboard

A filterable board in the spirit of Power BI. Explore distributions, correlations, and the model results, all in your browser.

A written analysis

It writes up the whole run in plain sentences, what it found and what to do next, in a report you can hand to someone.

Predict and export

Score new files, download the predictions, and take the model with a ready to run code snippet and the column list.

It learns and answers

It remembers past runs to recommend by analogy, and you can ask it questions that it answers from real guidance, with the sources shown.

What it handles

It works out the problem, not just the numbers.

AutoDS reads your target column and figures out which kind of problem you have, then adapts on its own.

Your dataWhat AutoDS does
A yes or no outcome, like churn or fraud Classification, with the right metrics for the balance of your classes
A number to predict, like price or demand Regression, with error you can actually read
No target, just rows to group Clustering, to surface the natural segments
A value that moves over time Forecasting, with seasonality and trend handled
Free text, like reviews or tickets Text classification, built on the words that matter
